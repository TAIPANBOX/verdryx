# verdryx 0.1.0

verdryx is the quality plane of the estate. It grades an agent's outputs against an eval set, with six graders (exact, regex, outcome tag, LLM judge, tool-call trace, and a typed verdict from typryx), or against TokenFuse's outcome tags. It stores runs in SQLite, flags quality drift against a stored baseline, turns TokenFuse's Parquet traces into cost-per-outcome reports, and computes SLO-style error budgets over the same traces. It measures and does not enforce: it writes no policy and gates nothing.

This is the first tagged release. verdryx is a command-line tool, not a server. It is not on PyPI, and there is no container image or binary; install it from the repository as the README describes. The suite collects 658 tests, and the README badge states the same number.

## Breaking

None. This release has no API, CLI, schema or stored-data change. Judge scores can move; see Migration.

## Migration

For operators who ran a build from main before this tag:

- **Re-baseline the llm_judge drift baseline.** The judge now sees a per-call output tag and a changed system prompt (#55), so its scores can shift once. After deploying, run the eval with this build and take the baseline again with `verdryx baseline <run_id>`. A drift check against the old baseline can report a one-time shift.
- **Re-run cost-per-outcome reports made by earlier builds over traces that include calls blocked for `unit_budget_exceeded` or `identity_mismatch`.** Those calls' avoided cost was counted as spend (#17).
- **Upgrade the Genaryx console.** A console built before #43 shows the eval mean without the unanswered count for typed runs.
- **Store upgrade is in place.** Opening an older store with this build adds the `eval_runs.agent_id` column and the `unanswered` table. `PRAGMA user_version` stays at 1. No manual step is needed.
- **Judge cost estimates changed for some models.** The price book now mirrors TokenFuse's rates (#46, #47, #50, #53). Compare costs across that change with this in mind.

## Not proven in this release

- Nothing is published. There is no release workflow, package, container image, binary or signature. The tag is a git reference only.
- The hosted judge (Jev) and the Claude judge have not been run live in the bake-off harness. The typed grader has run against a local model (qwen2.5:7b via Ollama) and a stub backend, not against the hosted typryx API.
- The judge fence (#55) is tested with a stub adapter and a mocked Anthropic client. It makes the closing tag unforgeable. It does not make a live judge model robust to hostile text inside the output block.
- The price mirror compares base rates against TokenFuse. The long-prompt tiers are held by a pinned test only, and the one-hour cache-write rate is not mirrored.
- Coverage is printed in CI, not gated.
