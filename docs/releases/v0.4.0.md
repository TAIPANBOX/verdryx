# verdryx 0.4.0

verdryx is the quality plane of the estate. In 0.4.0 the LLM judge stops guessing a score from a reply that does not carry one, and the price book matches tokenfuse's current price book, so cost figures for the newest models are no longer missing or stale. Both came from comparing verdryx with the other planes of the estate on real traces.

verdryx is still a command-line tool, not a server. It is not on PyPI, and there is no container image or binary; install it from the repository.

## What changed (#69 to #74)

**The LLM judge reads a score or refuses**

- The judge took the first number anywhere in a reply and clamped it, so a reply such as "1 of 5 criteria met, 0.2" became 1.0 and reached drift and error-budget measurements. The judge prompt now asks for one exact line, `SCORE: <number>`, with a decimal in [0, 1], and the parser reads that line alone (#73).
- Any other reply is refused with a reason, and the run counts it as unanswered in `EvalRun.unanswered`. Nothing is clamped.

**The price book follows tokenfuse**

- Rows for Claude Fable 5.2 are added (#70).
- Rows for `gpt-6.2-astra` and `gpt-6.2-sol` are added, as tokenfuse prices them (#72).
- The price book mirrors tokenfuse's current book: 50 base rows and five long-prompt tiers (#74).

**Documentation**

- The README and both diagrams show six graders, not four, with the tool-trace and typed graders included (#69).
- A hold is described as covering the agent's calls, not only its tool calls (#66).
- The test badge matches the collected suite (#72).

**Estate manifest**

- `verdryx-slo` is listed as a routine that both launchers run (#67).

## What an upgrade changes

An LLM judge reply that is not the single line `SCORE: <number>` is now refused, where 0.3.0 accepted the first number it found. Runs that used such replies will show as unanswered instead of scored, so their pass rates and drift readings can move. Rerun a suite that depends on the judge before comparing it with an earlier report.

Cost figures for the models above now come from the new rows. A run on a model that is not in the book still costs 0.0, as before.
